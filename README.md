# MobiCidade
Sistema para gestão de uma frota compartilhada de bicicletas e patinetes elétricos em ambiente urbano, controlando estações de docking, usuários e o ciclo de vida de cada corrida — do desbloqueio na estação de origem até a devolução na estação de destino. O sistema controla a autonomia de bateria dos patinetes e a necessidade de manutenção.
